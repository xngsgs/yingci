# v0.2 验证记录

日期：2026-10-23。保留 `VALIDATION.md` 的 v0.1 记录。

## 已完成的程序验证

- 27 项 Node.js 契约与集成测试通过：包括原有 16 项，以及创作方向校验、局部修改范围、重新构思、原有锁定保护、Midjourney 格式、文本完整性检查、版本差异、本机像素取色、JSON mode 和旧项目兼容。
- 局部微调模式要求模型明确返回修改字段；未声明的字段由程序保留，缺少修改范围的结果不应用。测试不证明模型对自然语言意图的理解准确。
- 老项目的创作方向使用默认值，无需批量重写或迁移原记录；新增建议、假设、用途与参考模式可持久化。
- 创作 JSON 导入复用服务端状态校验，分配新 ID；未知连接密钥字段会被丢弃，不覆盖现有项目。
- HTTP 往返验证：创作方向、自定义名称、建议假设与完整版本可保存、重新读取，并以新 ID 建立副本；原记录保持不变。这是接口与数据验证，不是导入按钮的浏览器验收。
- 示例主体锁定后不会把构图改成另一个主体；中英文组成的提示词都保留原主体。
- 发布前检查了 117 个唯一界面 ID、JavaScript 的直接 ID 引用、实际运行服务的静态资源与密钥接口屏蔽；待提交文件未检出凭证特征，`.env` 和 `.local` 不在版本文件中。此检查不能替代实际交互与布局验收。
