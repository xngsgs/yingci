# v0.1.0 验证记录

日期：2026-10-23。平台：Windows，Node.js 24.21.0；Codex 内置浏览器。

## 已验证

- `npm run check`：全部 JavaScript 语法检查通过。
- `npm test`：16 项契约和集成测试通过，覆盖双语字段锁定、输入与图片边界、结构化输出错误、密钥脱敏、跨源请求、配置持久化、并发限制、创作文件恢复与路径校验。
- 浏览器预设示例：锁定光线，把主体从咖啡改成小猫；中英切换；复制；手动编辑中英文要素；恢复早期版本且保留历史。
- 本机存储：修改后刷新，恢复第 2 版和光线锁定状态。内置浏览器出现 IndexedDB 配额限制，因此最终实现改为本机文件原子保存，未依赖浏览器存储额度。
- 图片上传：通过文件选择器上传随项目附带的示例 PNG，浏览器缩小/转换后保存在本机；未接入模型时引导连接，不伪造分析结果。
- 响应式：390 × 844 下检查对话、参考图、提示词切换，无水平溢出；1280 × 900 下检查三栏布局。测试后恢复浏览器默认尺寸。
- 隔离模拟模型：单独的 4329 端口、独立数据目录与假密钥；通过真实 HTTP 请求验证图片随请求发送、用户消息/回复更新、锁定光线保留、格式错误后的可重试状态、取消请求、提示词复制与 Markdown 下载。模拟服务没有调用外部 AI。
- 截图 `studio-preview.jpg` 来自实际运行的 4328 预设示例界面，未将模拟模型联调截图作为真实模型结果。
