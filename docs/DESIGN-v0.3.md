# v0.3 功能工作区

把用户的生图流程接起来：找方向 → 整理提示词 → 在生图工具使用 → 带结果回来改 → 收藏可复用的方案。

导航增加灵感库和效果复盘。灵感库包含人工编写的风格预设与本机收藏；记录继续负责完整对话和版本，不把两者混为一谈。现有项目和图片保留。

## 设计计划

- 沿用画布 #f1f3f8、白纸 #ffffff、正文 #292838、导航 #2d2b3c、雾紫 #7761a6；提示色使用原有浅紫 #f0eaf8。
- 字体沿用本机 Segoe UI Variable / Microsoft YaHei UI，页面标题 28px、条目标题 18px、正文 13–15px。
- 灵感库以左对齐的风格标题、实际配色与具体光影描述呈现预设，收藏可搜索名称、标签与提示词。不制作假生成效果图。
- 复盘页面左侧放用户的实际结果图，右侧填写明确问题并显示当前提示词。发送前明确哪些图片交给模型；没有连接时保留输入，提供连接入口。
- 桌面窄导航与移动端工作区导航提供相同入口。原有参考/对话/提示词标签仅用于创作页。

## 方案复核

新入口对应可完成的工作：选择风格、保存并复用提示词、根据生图结果改进。预设不替换已有主体，默认仅应用光线、配色和画风，并保留锁定项。复盘不使用本机假分析：本地只整理用户勾选的问题，实际图片分析走已配置模型与现有校验。
