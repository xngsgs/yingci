# v0.2 创作室

目标：让不懂提示词的人看清参考、表达想法、理解改动，并得到可复制的完整文本。

## 视觉方向

延续映词的雾紫标识，加入深色窄导航与浅灰蓝画布。照片作为唯一强烈的视觉焦点，提示词像一张独立稿纸，对话保持自然的阅读顺序。

- 色彩：画布 `#f1f3f8`，稿纸 `#ffffff`，正文 `#292838`，导航 `#2d2b3c`，操作色 `#7761a6`，轻提示 `#f0eaf8`。
- 字体：Segoe UI Variable / Microsoft YaHei UI / PingFang SC，继续使用本机字体；不用远程字体 CDN。主标题 27px，面板标题 19px，正文 12–14px，完整提示词 13–14px。
- 布局：左侧参考图、真实取色和参考范围；中间创作方向、对话和输入；右侧完整提示词与画面要素切换。窄屏改为三个标签面板，创作记录入口保留在顶栏。
- 动效：只保留输入焦点、选中状态和等待指示；尊重 reduced motion。

自检：第一轮的淡色正文对比不足，已压深浅色背景上的文字；减少次要提示占用的面积。去掉默认直接展示六个长字段的方式，先让用户看完整提示词，再按需进入要素编辑。没有加入评分百分比、装饰统计或模拟生成图。

## 功能与效果

- 创作方向包括想法、用途、参考方式、局部微调/重新构思；改变参考方式时联动所参考的画面要素。
- 模型须说明局部修改范围；服务端保留范围外的旧字段，并继续强制保留锁定项。未说明范围的局部修改不会直接应用。
- 展示一句话需求理解、可展开的建议假设，以及程序算出的实际改动。
- 版本比较展示字段的前后原文；撤销产生新版本，保留历史。
- 通用自然语言输出与 Midjourney `--ar` / `--no` 格式导出。只使用已核对的参数，不替用户猜模型版本、seed 或权重。
- 本机图片取色只读取当前图像像素，不调用 AI。
- 备份 JSON 包含参考图、对话、版本和创作方向；不包含模型连接配置。导入生成新记录，不覆盖原记录。

## 外部接口依据

- [官方 OpenAI structured outputs 文档](https://developers.openai.com/api/docs/guides/structured-outputs)：JSON mode 为显式可选兼容设置，仍执行本机结果校验。
- [Midjourney 参数文档](https://docs.midjourney.com/hc/en-us/articles/32859204029709-Parameter-List)：参数置于提示词末尾。

模型真实理解与生图效果需在接入用户选择的视觉模型后另行评估；契约测试和模拟联调仅证明程序规则与流程。
