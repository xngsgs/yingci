# v0.3 验证记录

日期：2026-10-23。保留 v0.1 与 v0.2 记录。

## 程序验证

- `npm run check` 通过；全部 54 项 Node.js 测试通过。
- 8 套双语预设均通过完整状态校验，搜索支持中文、英文与分类；借用画风仅更新未锁定的光线、配色、画风，不把例子中的人物或产品带入原主体。
- 收藏夹原子保存与重新读取、名称/标签校验、路径校验、500 条上限及并发操作通过验证。收藏仅保留名称、标签、双语画面要素与时间，额外图片/对话/连接字段被剥离。
- HTTP 验证了收藏 CRUD、跨来源和缺少应用请求头时拒绝写入。
- 模拟提供商接收到明确标注的目标参考图与实际生成结果图。局部修改范围外的内容和锁定内容由服务端保留；无效反馈、无草稿或错误图片在调用前被拒绝。
- 复盘问题、备注与结果图可随项目保存并重新读取，列表元信息不含结果图。老项目无需批量重写，未保存的复盘内容使用空状态。
- 取消按具体待发送消息身份处理。复盘取消不会删除此前用户消息，切换项目不会把旧输入恢复进新项目，重复取消安全。

## 代码复核后修复

- 结果图压缩期间禁止提交；选择序号使旧压缩结果不能覆盖后来选择、移除或切换项目的状态。
- 备注在输入时同步内存，避免图片准备完成时重绘丢失未失焦的文字。
- 复盘发送提示包含近期对话和创作方向；示例切入自由模式时清除预设观察，避免被标成真实 AI 分析。
- 辅助小标题加深颜色，改善对白底的文字对比度。
- 对话中仅显示用户勾选的问题与补充说明，程序发给模型的格式指令不混入用户聊天。
- 运行中的本机服务可读取新增资源与收藏接口；165 个界面 ID 唯一，前端直接 ID 引用与相对模块导入完整。待提交源码未检出凭证特征，私密配置和 `.local` 数据不在版本文件中。
